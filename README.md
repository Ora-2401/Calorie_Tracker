# 🍎 Calorie Tracker (Java)

A simple **Java console application** that allows users to input their daily calorie intake and provides feedback on whether the intake is **below**, **within**, or **above** the recommended range.

---

## 📌 Features
- Accepts user input for daily calorie intake
- Validates that input is numeric
- Categorizes calorie intake:
  - **Below 1500** → Below recommended range
  - **1500 – 5000** → Within recommended range
  - **Above 5000** → Above recommended range
- Handles invalid input with an error message

---

## 🛠️ Technologies Used
- **Java SE**
- **Scanner** for user input
- **Exception Handling** for input validation
